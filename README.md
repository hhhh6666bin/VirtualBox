#This is my VirtualBox ROS code
这是我根据b站赵虚左老师学习ros1 的手敲代码C++版本，在virtualBox上安装的ubantu20.04版本，ROS1是noetic版本，从通信机制（话题通信，服务通信，参数服务器通信），通信机制进阶，launch文件的使用，常用工具箱（TF坐标变换，rviz可视化工具箱，rosbag工具箱，gazebo仿真环境搭建），urdf机器人搭建，机器人导航实现，自主建图与定位
demo03_ws存储的是通信机制和进阶相关代码
demo04_ws存储的是tf坐标变换 rosbag工具包
demo05_ws存储的是urdf机器人搭建实现和导航实现
github存储的是开源的机器人模型和仿真房间
